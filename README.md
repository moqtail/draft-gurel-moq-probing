# Bandwidth Probing with Relay-Generated Tracks in Media over QUIC Transport

This is the working area for the Internet-Draft, "Bandwidth Probing with Relay-Generated Tracks in Media over QUIC Transport".

* Editor's Copy: open the latest run of the
  [Build Draft](https://github.com/moqtail/draft-gurel-moq-probing/actions/workflows/build.yml)
  workflow and download the `draft` artifact (HTML, TXT and PDF).
* [Datatracker Page](https://datatracker.ietf.org/doc/draft-gurel-moq-probing)
* [Working Group Draft](https://datatracker.ietf.org/doc/html/draft-gurel-moq-probing)

## Command Line Usage

Formatted text and HTML versions of the draft can be built using `make`.

```sh
$ make
```

Command line usage requires that you have the necessary software installed.  See
[the instructions](https://github.com/martinthomson/i-d-template/blob/main/doc/SETUP.md).

A PDF can be produced locally from the HTML with Chrome:

```sh
$ make
$ "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
    --no-pdf-header-footer --print-to-pdf="$PWD/draft-gurel-moq-probing.pdf" \
    "file://$PWD/draft-gurel-moq-probing.html"
```
